- VCC/GND
- Resistors


Connections:

ESP32 GPIO21 -> MPU6050 SDA
ESP32 GPIO22 -> MPU6050 SCL

Physical switches -> ECG chip MODE0/MODE1/MODE2


Important architecture:

The ESP32 does NOT control ECG mode.

The physical switches directly control the ECG custom chip.

8. ecgsim.chip.c
============================================================

Purpose:
Implements the ECG simulator itself.

Responsibilities:

- Read MODE0/MODE1/MODE2
- Select simulated heart rate
- Generate ECG waveform
- Output ECG waveform through ECG_OUT


Heart-rate modes:

MODE0 -> 55 BPM
MODE1 -> 75 BPM
MODE2 -> 110 BPM


get_bpm():

Reads the mode pins using pin_read().

MODE0 HIGH:
55 BPM

MODE1 HIGH:
75 BPM

MODE2 HIGH:
110 BPM

Default:
75 BPM


Important:

get_bpm() generates the simulated/reference heart rate
used to construct the ECG waveform.

It is NOT the BPM measured by the ESP32.

This prevents the ESP32 from simply knowing the answer

============================================================
12. ECG SAMPLING
============================================================

Sampling frequency:

250 Hz

Buffer:

2000 samples

Time represented:

2000 / 250 = 8 seconds


Therefore the system processes approximately
8 seconds of ECG data per buffer.


============================================================
13. R-PEAK DETECTION
============================================================

CardialState first finds:

minimum ECG value
maximum ECG value


Adaptive threshold:

threshold =
    minValue
    + 0.60f * (maxValue - minValue)


A sample is considered an R peak when:

- It is a local maximum
- It is above the threshold
- It is sufficiently far from the previous peak


Refractory period:

250 ms


This prevents multiple detections of the same heartbeat.


============================================================
14. RR INTERVAL
============================================================

The last two detected R peaks are used.

difference:

r2 - r1


Convert samples to seconds:

RR =
    difference / SAMPLE_RATE


============================================================
15. BPM CALCULATION
============================================================

BPM:

60 / RR


Expected values:

55 BPM:
RR ≈ 1.09 s

75 BPM:
RR = 0.80 s

110 BPM:
RR ≈ 0.545 s


The ESP32 calculates these values from detected R peaks.

============================================================
27. IMPORTANT DESIGN PRINCIPLE
============================================================

The ECG custom chip simulates the patient.

The ESP32 measures the simulated patient.

The custom chip knows the simulated/reference BPM.

CardialState independently derives BPM from ECG signal.


Therefore:

Simulation:

Switch
  -> ECG chip
  -> simulated ECG


Measurement:

ECG
  -> ADC
  -> R-peak detection
  -> RR
  -> BPM


This separation makes the system closer to an actual
physiological monitoring architecture.
